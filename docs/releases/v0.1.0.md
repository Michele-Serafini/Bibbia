Prima versione di Bibbia per Windows con interfaccia WinUI 3 nativa e motore Rust.

Scarica **Bibbia-Setup-0.1.0-x64.exe**, aprilo e segui la procedura. L'installer è offline e non richiede privilegi di amministratore, Rust, .NET o Visual Studio sul PC di destinazione. Richiede Windows 10 versione 2004 o successiva, oppure Windows 11, a 64 bit.

- Bibbia Diodati 1649 italiana e KJV inglese complete, disponibili offline.
- Lettura per libro e capitolo, ricerca e ripresa dall'ultimo versetto selezionato.
- Evidenziazioni, sottolineature, note e segnalibri locali in SQLite.
- Importazione di altre traduzioni JSON autorizzate, tema Windows/chiaro/scuro e dimensione del testo.
- Collegamento nel menu Start, collegamento desktop facoltativo, aggiornamento e disinstallazione con conservazione dei dati personali.

Build verificata: https://github.com/Michele-Serafini/Notion/actions/runs/40106811927

Sono passati i 7 test Rust su Linux e Windows, le verifiche C# → Rust, l'avvio WinUI e la ricerca mediante controlli reali, installazione, aggiornamento, blocco con app aperta, disinstallazione e conservazione dei file personali su un runner Windows Server 2022.

Il checksum SHA-256 è nel file `.exe.sha256` allegato. L'installer non è firmato digitalmente: Windows può mostrare un avviso SmartScreen. Le prove manuali su PC Windows 10/11 con differenti DPI e contrasto elevato restano consigliate.

Le evidenziazioni riguardano il versetto intero. Audio, piani di lettura e sincronizzazione cloud non sono inclusi. Progetto indipendente, non affiliato a Bible.com/YouVersion.
